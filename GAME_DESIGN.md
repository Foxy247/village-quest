# Village Quest – Game Design

## Core idea

Village Quest is a browser-based RPG set in
a small medieval village.

## Player

The player starts as an inexperienced villager.

## Core Gameplay Loop

Accept Quest
↓
Travel
↓
Explore / Gather / Fight
↓
Receive Resources
↓
Complete Quest
↓
Improve Character
↓
Unlock new content

## Character

- Name
- Level
- Experience
- Health
- Energy
- Gold

## Locations

- Village Square
- Tavern
- Ranger Lodge
- Blacksmith
- Forest
- Mine
