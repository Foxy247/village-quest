# Village Quest

Village Quest is a browser-based RPG learning project.

I am developing this project to learn and understand the fundamentals of software development through practical implementation.

## Project Goals

With Village Quest, I want to learn and practise the following technologies and concepts:

* PHP
* Object-oriented programming
* MVC architecture
* JavaScript
* HTML and CSS
* SQL and MySQL
* Git and GitHub
* Secure handling of user input
* Database access with PDO

## Planned Game Features

The game will gradually include features such as:

* Character creation
* Player attributes such as health, energy, experience, and level
* Locations and travel
* Inventory and items
* Equipment
* Quests
* Enemies and combat
* Merchants
* User registration and login
* Saving and loading game progress

## Technical Approach

The project is being developed without large frameworks so that I can understand the underlying concepts first.

The planned technology stack includes:

* PHP for the backend and game logic
* MySQL as the relational database
* JavaScript for browser interactions
* HTML and CSS for the user interface
* A simple object-oriented MVC structure
* Git and GitHub for version control

## Project Status

The project is currently in an early development and learning phase.

The current focus is on:

* Setting up the project structure
* Learning Git and GitHub
* Creating the first user interface
* Introducing object-oriented programming
* Building a simple MVC architecture

## Learning Approach

The goal is not only to build a working game.

I also want to understand:

* How data flows through a web application
* How classes and objects are used
* How responsibilities are divided between models, views, and controllers
* How data is validated and stored securely
* How relational databases are designed
* How errors are found and fixed systematically
* How software changes are documented with Git commits
